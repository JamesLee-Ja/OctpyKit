pdftool 開発手順書

1. 依存関係のインストール（初回のみ）
コマンドプロンプトで以下を実行：
pip install -r requirements.txt

（PowerShellで実行がブロックされる場合は、代わりに以下のコマンドを使用：
python -m pip install -r requirements.txt ）

requirements.txt に含まれる依存パッケージ：
- pypdf（PDFの読み込み・結合・分割に使用）
- tkinterdnd2（ドラッグ＆ドロップ機能に使用）

2. ソースコード構成
pdftool/
├── src/
│   └── pdftool/
│       ├── __init__.py      … パッケージ化のための空ファイル
│       └── pdftool.py       … 本体プログラム（GUI・結合/分割処理）
├── pdftool.spec              … PyInstaller用のビルド設定ファイル
├── requirements.txt
└── .gitignore

3. プログラムの実行方法（開発時）
プロジェクトのpdftoolディレクトリで以下を実行：
python src\pdftool\pdftool.py

操作手順：
【結合タブ】
(1) ウィンドウ上部の水色エリアに複数のPDFファイルをドラッグ＆ドロップする
    ※「PDFファイルを選択」ボタンからの複数選択も可能
(2) 一覧に追加されたファイルの結合順序を「↑ 上へ」「↓ 下へ」で調整する
    ※不要なファイルは「選択削除」、まとめて消す場合は「全てクリア」
(3) 「参照...」ボタンで出力ファイル名を指定する
(4) 「結合開始」ボタンをクリックすると、指定した順序でPDFが1つに結合される

【分割タブ】
(1) ウィンドウ上部の水色エリアに分割したいPDFファイルを1つドラッグ＆ドロップする
    ※「PDFファイルを選択」ボタンからの選択も可能
(2) 分割方法を選択する
    - 「1ページごとに分割」… 全ページを1ファイル1ページに分割
    - 「ページ範囲を指定して分割」… 例：1-3,4-6,10 のようにカンマ区切りで入力
      （範囲または単一ページを指定可能、全ページ数を超える範囲はエラーになる）
(3) 「参照...」ボタンで出力フォルダを指定する
(4) 「分割開始」ボタンをクリックすると、指定した方法でPDFが分割・出力される

4. 独立したexeファイルへのパッケージ化（任意、Pythonがない環境でも実行可能にする）
(1) pyinstallerのインストール：
pip install pyinstaller
（PowerShellでブロックされる場合：python -m pip install pyinstaller ）

(2) pyinstallerでビルド：
pdftool.spec を使ってビルドする場合（推奨、設定済みのオプションが反映される）：
pyinstaller pdftool.spec

spec を使わず直接指定する場合：
pyinstaller --onefile --windowed --icon=app.ico src/pdftool/pdftool.py

生成された実行ファイルは dist\pdftool.exe に出力される。

5. 生成物の扱いについて
build/ と dist/ フォルダはビルド時に自動生成される一時ファイル・実行ファイルであり、
.gitignore に設定済みのため Git の管理対象には含めない。

6. 今後の拡張予定
現バージョンは「結合」「分割」の2機能のみ実装済み。
今後、以下の機能をタブとして追加予定：
- 透かし追加（文字水印、透明度・位置を指定可能）
- 暗号化／復号（PDFの開くパスワードの設定・解除）
