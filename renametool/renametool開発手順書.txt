renametool 開発手順書

1. 依存関係のインストール（初回のみ）
コマンドプロンプトで以下を実行：
pip install -r requirements.txt

（PowerShellで実行がブロックされる場合は、代わりに以下のコマンドを使用：
python -m pip install -r requirements.txt ）

requirements.txt に含まれる依存パッケージ：
- tkinterdnd2（ドラッグ＆ドロップ機能に使用）
※その他はすべてPython標準ライブラリのみで実装している

2. ソースコード構成
renametool/
├── src/
│   └── renametool/
│       ├── __init__.py          … パッケージ化のための空ファイル
│       └── renametool.py        … 本体プログラム（コアロジック＋GUI）
├── renametool.spec               … PyInstaller用のビルド設定ファイル
├── requirements.txt
└── .gitignore

renametool.py の内部構成：
- 前半：画面に依存しないコアロジック（絞り込み、リネーム計画の作成、競合検出、
        リネーム実行、元に戻す用ログ）をモジュール単位の関数として実装
- 後半：tkinterによる画面（RenameToolApp クラス）がコアロジックを呼び出す

3. プログラムの実行方法（開発時）
プロジェクトのrenametoolディレクトリで以下を実行：
python src\renametool\renametool.py

操作手順：
(1) 対象を指定する
    - 水色のエリアにフォルダまたはファイルをドラッグ＆ドロップする
      （「フォルダを選択」「ファイルを選択」ボタンからの指定も可能）
    - フォルダ内のサブフォルダも処理する場合は「サブフォルダも含める」にチェックを入れる
    - フォルダ走査では、隠しファイル・システムファイルは対象外
      （明示的にドロップ／選択したファイルは対象になる）

(2) 絞り込み条件を設定する（空欄の場合は、対象のすべてのファイルが処理対象）
    - 一致方法：ワイルドカード／含む文字／正規表現
    - 条件：複数指定する場合は ; （全角 ； も可）で区切る
      例）*.jpg;*.png ／ IMG ／ ^IMG_\d+
    - 「大文字小文字を区別」にチェックすると区別して判定する
    - 条件に合致しないファイルは、プレビューにも表示されず変更もされない

(3) リネームルールを選択して、パラメータを設定する（いずれか1つを選択）
    - 検索して置換　　　：検索文字列→置換後の文字列（「正規表現を使う」で正規表現も可）
    - 前後に文字を追加　：先頭に追加する文字、末尾（拡張子の前）に追加する文字
    - 連番　　　　　　　：名前テンプレート（{n}＝連番は必須、{name}＝元の名前は任意）、
                          開始番号、増分、桁数（ゼロ埋め）
                          例）写真_{n} → 写真_001.jpg
    - 日付を付加　　　　：日付の種類（更新日時／作成日時／現在日時）、書式、
                          付加位置（先頭／末尾）、区切り文字
    - 大文字小文字・拡張子：ファイル名の大文字小文字変換、拡張子の変換または指定した拡張子への変更
    ※いずれのルールも、拡張子は変更しない設定が基本（拡張子の変更は最後のモードのみ）

(4) 「プレビュー」ボタンをクリックして、変更内容を確認する
    - 状態：変更／変更なし／競合／不正な名前／エラー
    - 競合・不正な名前・エラーの行は赤字で表示され、備考欄に理由が表示される
    - 競合の例：変更後の名前が他のファイルと重複、同名のファイルが既に存在する
    - 不正な名前の例：使用できない文字（\ / : * ? " < > |）、名前が空になる、
      末尾にスペース／ピリオド、予約名（CON、NUL など）

(5) 「リネーム実行」ボタンをクリックする
    - 赤字の行が1件でもある場合は実行できない（ルールや絞り込み条件を見直す）
    - プレビュー後に設定を変更した場合は、もう一度プレビューが必要
    - 実行結果（成功・失敗の件数）がダイアログで表示される

(6) 間違えた場合は「直前の操作を元に戻す」ボタンで取り消す
    - 直前1回分のリネームを元の名前に戻せる
    - 元に戻す用の記録は %APPDATA%\OctpyKit\renametool_last.json に保存される
      （アプリを再起動しても元に戻せる）

4. 注意事項・仕様上の補足
- 連番は、サブフォルダを含めた場合も、全フォルダを通して連続した番号になる
  （自然順ソート：file2 は file10 より前）
- 実行時は一時的な名前を経由して変更するため、名前の入れ替え（a↔b）や
  連鎖（1→2、2→3）、大文字小文字だけの変更でも途中で衝突しない
- 一部のファイルで失敗した場合は元の名前に戻され、失敗した件数と理由が表示される
- フォルダ名自体はリネームの対象外

5. 独立したexeファイルへのパッケージ化（任意、Pythonがない環境でも実行可能にする）
(1) pyinstallerのインストール：
pip install pyinstaller
（PowerShellでブロックされる場合：python -m pip install pyinstaller ）

(2) pyinstallerでビルド：
renametool.spec を使ってビルドする場合（推奨、設定済みのオプションが反映される）：
pyinstaller renametool.spec

spec を使わず直接指定する場合：
pyinstaller --onefile --windowed --icon=app.ico src/renametool/renametool.py

生成された実行ファイルは dist\renametool.exe に出力される。

6. 生成物の扱いについて
build/ と dist/ フォルダはビルド時に自動生成される一時ファイル・実行ファイルであり、
.gitignore に設定済みのため Git の管理対象には含めない。

7. 今後の拡張予定（候補）
- 複数ルールの組み合わせ（例：置換したうえで連番を付加）
- 連番をフォルダごとに採番し直すオプション
- 拡張子別・更新日時順など、並び順の指定
